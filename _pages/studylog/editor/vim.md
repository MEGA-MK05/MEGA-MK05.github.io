# Vim 에디터 학습 보고서

작성자: 김민규
작성일: 2025-06-09

---

## 1. 학습 동기

기존에 사용하던 GUI 기반의 코드 에디터는 무겁고, 터미널 기반의 환경에서는 비효율적이었다. 특히 서버에서 작업하거나 SSH로 원격 접속할 때 빠르고 가벼운 에디터의 필요성을 느꼈고, 이에 따라 `vim`을 공부하게 되었다.

---

## 2. Vim 소개

`vim`은 "Vi IMproved"의 약자로, UNIX 계열 시스템에서 널리 사용되는 텍스트 편집기다. 경량이면서도 강력한 기능을 제공하며, 다양한 플러그인을 통한 확장도 가능하다.

---

## 3. 학습 내용 정리

### 3.1 기본 모드 체계 이해

Vim은 총 3가지 주요 모드를 기반으로 동작한다.

| 모드 | 설명 |
|------|------|
| Normal 모드 | 기본 명령 모드, 대부분의 명령어 실행 |
| Insert 모드 | 텍스트 입력 모드 |
| Visual 모드 | 블록 선택 및 복사/삭제 등 수행 가능 |

#### 모드 전환 명령어

- `i` : Insert 모드로 전환
- `Esc` : Normal 모드로 복귀
- `v` : Visual 모드 진입
- `V` : 라인 단위 Visual
- `Ctrl + v` : 블록 단위 Visual

---

### 3.2 기본 명령어

#### 파일 열기 / 저장 / 종료

```bash
vim filename      # 파일 열기
:w                # 저장
:q                # 종료
:wq               # 저장 후 종료
:q!               # 저장하지 않고 종료

### 3.2 기본 명령어

#### 파일 열기 / 저장 / 종료

```bash
vim filename      # 파일 열기
:w                # 저장
:q                # 종료
:wq               # 저장 후 종료
:q!               # 저장하지 않고 종료
```

#### 커서 이동

| 명령어 | 설명 |
|--------|------|
| h / j / k / l | 좌 / 하 / 상 / 우 이동 |
| w / b         | 단어 기준 앞으로 / 뒤로 이동 |
| gg / G        | 문서의 처음 / 끝으로 이동 |

#### 복사, 붙여넣기, 삭제

| 명령어 | 설명 |
|--------|------|
| yy     | 현재 줄 복사 |
| p      | 붙여넣기 |
| dd     | 현재 줄 삭제 |
| x      | 문자 하나 삭제 |

#### 검색 및 치환

```vim
/foo           # 'foo' 찾기
n              # 다음 검색 결과로 이동
:%s/foo/bar/g  # 전체 문서에서 'foo'를 'bar'로 치환
```

---

### 3.3 .vimrc 설정

사용자 설정은 홈 디렉토리의 `.vimrc` 파일을 통해 가능하다.

```vim
set number              " 줄 번호 표시
set tabstop=4           " 탭 크기 설정
syntax on               " 문법 강조
set autoindent          " 자동 들여쓰기
```
